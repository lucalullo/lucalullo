# Luca Lullo - Independent Data & AI Practitioner

Independent **Data & AI Practitioner** focused on data engineering, advanced data cleaning, applied machine learning, and AI systems.

I build **reproducible data pipelines, high-quality datasets, predictive models, AI agents, and language-model systems**, with a strong emphasis on transparency, experimentation, evaluation, and practical implementation.

My work spans:

- data integration, cleaning, validation, and quality control;
- exploratory data analysis and reproducible research;
- feature engineering and predictive machine learning;
- model evaluation, explainability, and interpretation;
- AI agents with routing, planning, tools, memory, and human escalation;
- agentic AutoML and experiment-driven ML systems;
- language models and Transformers implemented from first principles;
- public, socioeconomic, institutional, and climate data analysis.

I primarily use **Python** to transform complex data into reliable, understandable, and reproducible systems and insights.
